# How this relates to the catalogs

omastore exists to help people use work that is already out there.
It is not a rival to [omarchytheme.com](https://omarchytheme.com) or
[omarchyplugins.com](https://omarchyplugins.com). Those remain the
places to browse in a browser, submit, and run the community.

This app is a terminal window onto the same public catalogs, then
the official Omarchy CLI does the install.

If you maintain one of those catalogs and want a wording change,
a link, or this client to stop, open an issue or email the
maintainer. That request comes first.
