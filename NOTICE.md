omastore is a terminal client. It does not own the catalogs it reads
or the themes and plugins those catalogs list.

## Catalogs

Theme listings are read from [limehawk's Omarchy Theme Website](https://github.com/limehawk/omarchy-theme-website)
([omarchytheme.com](https://omarchytheme.com)). That project's original
code is MIT licensed. Theme repositories, names, previews, and README
text remain the work of their authors.

Plugin listings are read from [HANCORE's Omarchy Plugin Marketplace](https://github.com/HANCORE-linux/omarchy-plugin-marketplace)
([omarchyplugins.com](https://omarchyplugins.com)). That project's
original marketplace code is MIT licensed. Their
[NOTICE](https://github.com/HANCORE-linux/omarchy-plugin-marketplace/blob/main/NOTICE.md)
applies: plugin code, repositories, names, trademarks, logos,
screenshots, and previews stay with their owners. A listing is not
endorsement.

The plugin marketplace credits [bjarneo](https://github.com/bjarneo)
for interface inspiration and limehawk's theme site for marketplace
structure.

## Installed works

`omastore install` clones the upstream git repository with the official
`omarchy theme install` or `omarchy plugin add` command. License and
copyright for that work are whatever the cloned repository states.
